## Scope and mode

Whole-site immersive presentation rooted at `src/app/layout.tsx` and `src/app/page.tsx`. Visitor mode: Experience.

## Audience, job, and action

Engineering peers and the broader technical community should quickly understand Leonardo’s SRE/software-engineering focus, then actively explore Projects, Infrastructure, Resume, Playground, and Contact as applications. Visitors must also be able to leave the immersive shell for conventional accessible pages.

## Proof and content

The desktop opens Welcome and a compact System Monitor preview. Typed project case studies remain files inside the Projects folder; typed playground entries become physical program disks; the sanitized infrastructure snapshot powers System Monitor; typed resume data powers its application. No invented commercial claims or fake live events.

## Direction

MKS/98 Hobbyist Repair Bench. Warm beige ABS, deep cobalt desktop, voltage-yellow focus, red only for errors, original compact pixel-like chrome icons, diagnostic boot typography, readable modern application content. Asymmetric Workbench composition: vertical icon rack left, large offset Welcome window, small System Monitor lower right, taskbar below. Mobile uses one maximized app plus compact launcher.

## Memorable moment

The visitor powers on the computer case and the same live CRT expands into MKS/98. Opening Program Disks reverses that move to reveal the repair bench; a selected experiment disk physically travels from the cabinet into the case drive before the CRT returns and launches it.

## Constraints

Fresh loads begin on the complete powered-off repair bench and boot only after the case power gesture. Boot is skippable. Canonical route HTML and metadata remain server-rendered. Accessible mode bypasses boot, sound, windows, and cinematic movement. The shared scene is original 2D DOM/CSS, supports keyboard and touch, and provides a reduced-motion crossfade.

## Unresolved

None. The power control lives on the case, Projects remain inside the screen, and playground programs use the physical disk cabinet.
